## Overview

Validating 3D geometry, dialing in physical material parameters (clearcoat, sheen, transmission, alpha masks), and bundling lightweight assets for web e-commerce usually forces a round-trip into heavy DCC suites like Blender. Mirage provides a focused, high-speed environment tailored for glTF 2.0 / WebGL pipelines.

## Architecture & Invariants

- **Strict Trust Boundary**: Clean separation across Main, typed Preload (45 methods), and Renderer with zero shared code, whitelist path enforcement via `fs.realpath`, and Zod validation on all 44 IPC channels.
- **Single WebGL Context & Zero-Recompile Uniforms**: Exactly one `<Canvas>` across the app; slider updates mutate `MeshPhysicalMaterial` uniforms directly without triggering unnecessary shader recompilations.
- **Native Texture & ORM Pipeline**: Asynchronous `.webp` thumbnail generation via `sharp` on libuv, multi-threaded ORM channel packing (`R=AO, G=Roughness, B=Metalness`), and `.glb` live reload via `chokidar`.
- **Agent Studio & MCP**: OpenAI-compatible streaming agent and Model Context Protocol client routed through a Human-in-the-Loop approval gate and `safeStorage`-encrypted key vault.
