## Context

Final project built for **Prácticas Profesionalizantes I (2026)** at **Instituto Superior Villa del Rosario (ISVR)** alongside Tomás Taborda, Valentín Hinojosa, and Ismael Botella.

## Architecture & Features

- **Typed npm Workspaces Monorepo**: Fastify v5 + Drizzle ORM + PostgreSQL 16 API backend, React 19 + Vite 8 + Tailwind CSS v4 web app, and shared TypeScript contracts (`@vetvault/shared`).
- **Clinical Records & Media**: Interactive pet charts tracking allergies, weight history, vaccinations, generated PDF prescriptions (`pdfmake`), and attachment storage in MinIO / S3.
- **Domain Integrations**: License validation against Colegio de Veterinarios de Córdoba, SENASA medication and vaccine catalog lookup, and Mercado Pago Checkout Pro subscriptions.
- **RAG Clinical Copilot**: Gemini (`@google/generative-ai`) assistant grounded in patient medical history with rate limiting and role-based call quotas.
